# 第1看：盈收与利润质量

## 职责

评估企业利润的含金量：营收趋势、扣非净利润、经营性现金流与净利润的匹配度、自由现金流可持续性、毛利率趋势。

## 调用方式

调用 MCP 工具 `look_01_profit_quality`：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| ts_code | string | Y | A股代码，如 "000002.SZ" |
| as_of_date | string | | 分析截止日 YYYY-MM-DD，默认今天 |
| lookback_years | int | | 回看年数，默认 3 |

## 返回结构解读

| 字段 | 说明 |
|------|------|
| status | `ready` / `not-applicable`（金融类） / `no-data` |
| company_profile | 公司基本信息、行业、是否金融类 |
| summary | 关键摘要指标 |
| rows | 逐年明细数据 |

## 分析框架

1. 只取合并报表年报数据，仅使用分析日之前可见的数据
2. 净现比 = 经营现金流净额 / 归母净利润，理想值 >= 1；仅归母净利润为正的年份纳入平均
3. 自由现金流 = 经营现金流 - 购建固定/无形/其他长期资产支付的现金
4. 毛利率趋势：按时间正序严格单调下降 >= 3 年 → `grossprofit_margin_declining_3y=true`
5. 净利率字段优先使用 netprofit_margin，覆盖率差则 fallback 到 profit_to_gr
6. 金融类公司（银行/保险/证券）不适用，直接返回 not-applicable

## 关键指标与红旗信号

- 扣非利润为正的年份数
- 经营现金流为正的年份数
- 自由现金流为正的年份数
- 净现比平均值 & 低于 1 的年份数（**净现比连续低于 0.5 为严重红旗**）
- 毛利率是否连续 3 年下滑（cross_validation: 若为 true，ask-q2 竞争优势须同步降分）

## 输出要求

向用户呈现：
- 数据质量摘要（覆盖年份、缺失项）
- 最近 N 年的逐年证据表（营收、净利润、现金流、派生指标）
- 红旗提示（若有）
- 趋势判断（改善/恶化/稳定）

## 与其他维度的关联
