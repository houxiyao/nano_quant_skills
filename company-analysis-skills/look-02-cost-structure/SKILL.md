# 第2看：费用成本结构

## 职责

分析四大费用率（销售/管理/财务/研发）的水平与趋势，判断费用增长是否与业务增长匹配。

## 调用方式

调用 MCP 工具 `look_02_cost_structure`：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| ts_code | string | Y | A股代码，如 "000002.SZ" |
| as_of_date | string | | 分析截止日 YYYY-MM-DD，默认今天 |
| lookback_years | int | | 回看年数，默认 3 |

## 返回结构解读

| 字段 | 说明 |
|------|------|
| status | `ready` / `not-applicable` / `no-data` |
| summary | 费用率摘要、匹配信号 |
| rows | 逐年费用率与原值 |

## 分析框架

1. 销售/管理/财务费用率使用 fin_indicator 现成字段
2. 研发费用率 = rd_exp / total_revenue * 100 派生
3. 费用与业务匹配度按方向一致性取证
4. 重点警示：销售费用增长为正但营收同比不增长
5. 金融类公司不适用

## 关键指标与红旗信号

- 四大费用率年度水平与变动趋势
- 销售费用与营收增长不匹配次数（**核心红旗**）
- 研发费用与营收增长不匹配次数
- 研发费用缺失情况
- 费用率异常突变（年度波动超过正常范围）

## 输出要求

向用户呈现：
- 最近 N 年四大费用率证据表
- 费用原值同比变化
- 匹配度分析结论
- 红旗提示

## 与其他维度的关联

- look-01（利润质量）：净利率下降可能源于费用率上升
- look-03（增长趋势）：营收增长数据共享

## 何时暂停

- 用户希望加入"高增长"明确阈值并据此自动评分
- 用户要求按行业差异设置不同费用率阈值
- 用户希望把期间费用率异常定义为固定数值阈值
